مهم:
- این خروجی فقط نسخه آزمایشی رابط کاربری است.
- چت فعلاً پاسخ واقعی هوش مصنوعی تولید نمی‌کند.
- پرداخت مایکت هنوز پیاده‌سازی نشده و نباید این APK را به‌عنوان نسخه دارای پرداخت منتشر کرد.
- برای اجرای workflow در GitHub Actions، پروژه را در یک repository آپلود کنید و از تب Actions، workflow با نام Build Nexa AI APK را اجرا کنید.
- پس از موفقیت، در صفحه اجرای workflow بخش Artifacts فایل Nexa-AI-debug-APK را دانلود کنید.
- این APK آزمایشی/debug است و برای انتشار عمومی کافی نیست؛ نسخه release باید با کلید امضای محافظت‌شده ساخته شود.
- برای ثبت برنامه و پرداخت مایکت، از شناسه محصول/کلید عمومی طبق مستندات رسمی و پنل توسعه‌دهندگان استفاده کنید.
- هیچ کلید خصوصی، رمز، یا اطلاعات بانکی را در مخزن یا چت قرار ندهید.
